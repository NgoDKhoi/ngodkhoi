AIoT / Robotics Nhóm 2 người

AutoClaw - AI Robot

Xe tự hành thông minh (Edge AI Robot) tích hợp điều khiển đa phương thức: thủ công, giọng nói tiếng Việt, cử chỉ bàn tay. Xử lý trực tiếp trên GPU Client kết hợp phanh khẩn cấp tự động và Telegram Bot.

Công nghệ

Rust (Tokio / PyO3) Python (Flask / OpenCV) C++ (Embedded / Arduino) Gemini 2.0 Vision AI MediaPipe (Edge AI) Raspberry Pi 4

Điểm nổi bật

  • Đa phương thức: Điều khiển qua cử chỉ tay (MediaPipe), giọng nói tiếng Việt và Web Dashboard.
  • Lõi an toàn (Safety Reflex): Viết bằng Rust chạy đa luồng, tự động phanh khẩn cấp chống va chạm.
  • Tuần tra tự trị: Tích hợp Gemini 2.0 Vision AI phân tích ảnh camera & sonar để tự né chướng ngại vật.
Hướng Dẫn Mã Nguồn
Game / Computer Vision Solo

Fruit Slash Game

Tựa game WebGL bảo vệ máy chủ kết hợp Computer Vision. Người chơi sử dụng chính bàn tay thật trước Webcam để chém mục tiêu theo thời gian thực nhờ công nghệ nhận diện cử chỉ độ trễ thấp.

Công nghệ

Unity (WebGL) C# MediaPipe (Edge AI) JavaScript (.jslib)

Điểm nổi bật

  • Hand Tracking: Nhận diện và theo dõi tọa độ bàn tay trực tiếp trên trình duyệt với độ trễ cực thấp.
  • Gesture Recognition: Tính toán khoảng cách tọa độ để nhận diện thao tác "Pinch" (nhón/chém).
  • Unity-Web Bridge: Sử dụng file .jslib đồng bộ dữ liệu ML từ JS vào game loop Unity.

Multiplayer Game Nhóm 4 người

Exploding Kittens Game

Game thẻ bài chiến thuật Multiplayer thời gian thực dựa trên Exploding Kittens (Mèo nổ) xây dựng trên Unity Engine và Firebase. Hỗ trợ hệ thống phòng chơi (Lobby) và thi đấu trực tuyến với bạn bè.

Công nghệ

Unity Engine C# Firebase Auth Realtime Database

Điểm nổi bật

  • Hệ thống tài khoản và đồng bộ tiến trình thông qua Firebase Authentication.
  • Cơ chế tạo phòng (Lobby), bắt cặp và thi đấu Online Multiplayer thời gian thực.
  • Tái hiện đầy đủ cơ chế thẻ bài chiến thuật (Explode, Defuse, Attack, Skip, Shuffle).
Hướng Dẫn Mã Nguồn
Classic Game / Algorithms Solo

Tetris Game

Tái hiện tựa game xếp gạch kinh điển bằng Unity Engine. Tập trung xử lý logic Grid System ma trận 2D, thuật toán xoay khối gạch và tối ưu WebGL Build chạy trực tiếp trên trình duyệt.

Công nghệ

Unity Engine C# WebGL Build 2D Grid Algorithm

Điểm nổi bật

  • Hệ thống Grid: Ánh xạ tọa độ không gian thực kiểm soát va chạm (Collision Detection) chính xác.
  • Tối ưu thuật toán: Xây dựng Rotation Matrix xoay khối, Spawner ngẫu nhiên và quét xóa hàng hiệu năng cao.
  • Game State Machine: Quản lý trạng thái luồng game chặt chẽ, mượt mà trên nền tảng WebGL.
